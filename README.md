# Professional IPTV Player

A premium IPTV web app skeleton with:
- Arabic and English interface toggle
- RTL/LTR layout support
- Live TV browsing
- Favorites and search
- EPG panels and channel groups
- VOD and series cards
- Responsive dark premium UI
- Playlist/Xtream settings panel
- Embedded HTML5 video player support

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Features included

- Live channels with category filters
- Stream player modal
- Favorites management
- EPG schedule view
- Arabic/English localization
- Mobile responsive layout
- Theme-ready polish for TV and desktop use
- Settings for playlist and account data

## Notes

This project is a front-end starter designed to support IPTV platforms, M3U playlists, and Xtream API data sources.
